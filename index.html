APPS & TOOLS

Apps & Tools

Tools I built to get more out of my own devices. All source code is on GitHub.

Android app

Razer Edge Tuner v0.2.0

A game tuner for the Razer Edge gaming tablet. Set up each game once — it applies your settings when the game starts and restores everything when you quit. Available in English and Korean.

  • Per-game refresh rate, aspect ratio and resolution
  • Quiet fan mode, heat guard and battery drain analysis
  • In-game FPS, temperature and ping overlay, controller check
  • Java
  • Android 12
  • Shizuku
  • KO / EN
View on GitHub
Windows app

Wireless Charger Chroma PC

Controls the lighting of the Razer Chroma wireless charger from a Windows PC. It mirrors the phone-only setup app and talks to the charger directly over USB or Bluetooth.

  • Color wheel, brightness and 4 effects (static, breathing, spectrum, wave)
  • Idle effect, status light and lighting timers
  • USB (HID) and Bluetooth LE protocols documented and implemented
  • C#
  • WebView2
  • USB HID
  • Bluetooth LE
View on GitHub
Windows app · 0.4.0 alpha

Synapse 2 Revive

Brings older Razer devices that only worked with Synapse 2 back to life with a modern, Synapse-style interface. It covers every Synapse 2 device and recognizes them as soon as they're plugged in.

  • 143 officially supported Synapse 2 devices + 32 more from its data files
  • Lighting, DPI, button and key remapping, macro recording
  • Headset equalizer, Chroma sync and usage stats
  • C#
  • WebView2
  • USB HID
  • Equalizer APO
Coming soon

All of these are unofficial personal projects and are not affiliated with Razer.
